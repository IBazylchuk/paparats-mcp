`module_map`: Uses and Used by are imports between the folders modules are named after, counted in importing files. A call matched only by its name (`x.clear()` on an object of unknown type) no longer makes a link, and an import into a folder no module is named after is no longer dropped: such folders are listed on their own lines, `Uses folders` and `Used by folders`.
